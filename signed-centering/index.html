Recenter a signed combination

Exact finite algebra · Conditional application

Read the standalone proof (PDF)

Input. Components with known signed leading profiles and controlled residuals; fixed coefficients that the downstream expression actually uses.

Output. An explicit center for the combined value and a residual-only error bound, not just a triangle-inequality bound on the uncentered terms.

Proof

Write each gⱼ=mⱼ+rⱼ, with |rⱼ|≤Eⱼ. For any coefficients aⱼ, Σaⱼgⱼ=Σaⱼmⱼ+Σaⱼrⱼ and |Σaⱼrⱼ|≤Σ|aⱼ|Eⱼ. If the values are complex, take the real part only after forming the signed center. When a common residual bound E is useful, specialize to Σ|aⱼ|E.

Worked use in the manuscript

An M=1 character calculation used A(y)=Re(g_q−g_d−g_qd). If the three centered profiles are all −2√y and their residual magnitudes are at most E(y), the correct center is +2√y and A(y)≥2√y−3E(y). Bounding the three uncentered terms individually instead gives only −6√y−3E(y). This difference concerns the conditional local path using chosen profiles, not every host or window.

Verification boundary

Archived focused Lean checks test the three-term center, 3E error and real-part lower bound. The actual host construction, higher-level orthogonality and supplied prime-selection hypotheses are distinct. The note does not claim a complete Lean rebuild of the manuscript or an arithmetic novelty for the triangle inequality.
