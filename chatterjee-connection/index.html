Direct application

Measure the discontinuity in Chatterjee’s correlation

The same operator appears in an independent population result for lower semilinear copulas. It does not use the Chen theorem.

The energy defect

Write Dδ=tδ′−δ for an absolutely continuous lower semilinear diagonal δ, with δ(0)=0, δ(1)=1 and 0≤Dδ≤δ almost everywhere. If δₙ→δ uniformly in the same class, then ξ(δₙ)−ξ(δ)=2‖Dδₙ−Dδ‖²_{L²(dt/t)} + o(1). Thus the operator measures the part of the correlation difference that uniform convergence need not remove.

What else is needed

One-sided approximation by linear and quadratic pieces is separate. Together these steps give the exact set [ξ(C),τ(C)] of possible limits along lower semilinear copulas converging uniformly to C. Each level is realizable by a sequence with that value at every term.
