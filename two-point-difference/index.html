Cancel a shared linear term before estimating

Exact finite identity · Conditional window application

Read the standalone proof (PDF)

Input. Two positive evaluation points x,y in the applicable range, the same profile and coefficients at both points, and any needed anchor, range and other-signal assumptions.

Output. A computable difference that does not contain the unknown common linear coefficient.

Proof

If A(t)=ct+F(t) on the interval, then A(y)−(y/x)A(x)=F(y)−(y/x)F(x). If the inverse P(t)=tA′₊(t)−A(t) is available, integrating (A/t)′ gives the more useful expression A(y)−(y/x)A(x)=y∫ₓʸ P(t)t⁻² dt. With the signed finite-sum profiles one can alternatively subtract their active terms directly; neither method needs separate bounds for the linear coefficient c.
